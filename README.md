
# 🏠 House Price Prediction — Robust Regression Engine

🔗 **Live Demo:** [Try the House Price Prediction App](https://robust-regression-engine-ml-project.streamlit.app/)

A machine learning project that predicts house prices using multiple regression algorithms, model evaluation, and an interactive Streamlit web application.

---

## 📌 Project Overview

The **Robust Regression Engine** predicts house prices in INR using property-related features. The project compares multiple regression models, applies hyperparameter tuning and cross-validation, and deploys the selected model through Streamlit.

### 🎯 Objective

Build and deploy a machine learning model that estimates house prices based on property characteristics.

**Target Variable:** `house_price_inr`

---

## ✨ Key Features

- 📊 Data preprocessing and feature preparation
- 🤖 Comparison of multiple regression algorithms
- ⚙️ Hyperparameter tuning and cross-validation
- 📈 Model evaluation using RMSE
- 🏆 Selection of the best-performing model
- 🌐 Interactive Streamlit web application
- 💾 Model export using Joblib

---
